# SPK

网络来源仅支持通过系统证书校验的 HTTPS，拒绝降级重定向；本地套件使用绝对路径的 `file://` URL。
可在地址末尾附加 `#sha256=` 和可信的 64 位十六进制摘要，完整读取并验证后才安装。
来源规则、超时和缓存行为见[主文档](../README.md)。
